# 招聘运行集成契约

Contract-Version: 0.1.0

## 证据状态与共同不变量

本契约只定义宿主适配者需要闭合的业务语义。当前所有能力的 `connection_status = required_not_connected`，`tool_evidence_status = none`。这意味着可以设计调用意图和模拟返回，但不能声明真实接口、租户权限、调用路径、性能或业务结果。

共同结果状态为 `success | empty | conflict | permission_denied | partial_success | failed`。Tool 成功只证明技术动作已发生，不证明岗位判断正确。新事实、权限变化、空结果、冲突或部分成功必须回到主 Agent 重判。契约不规定端点、私有字段、错误码、固定重试、幂等键或覆盖策略；这些由有权平台文档和业务责任人共同确认。

每个适配器返回足以识别本次任务与对象的权威身份、结果状态、可用事实、未完成对象、权限与副作用收据、数据当前性以及恢复入口。没有稳定对象身份或收据时，降低重复执行和跨会话恢复声明。

## 重复、修订与恢复

完全相同的请求、显式重做、岗位或标准修订以及包含外部副作用的恢复具有不同业务含义，不能由模型统一决定覆盖或重放。宿主需要提供稳定任务／对象身份、已发生副作用和有权的版本关系；缺少这些事实时，Agent只呈现当前会话内结果并停止重复外发。

Trace 的最小内容是对象身份、标准身份与版本、决定性证据定位、用户授权、Tool 收据、未解决冲突、部分完成结果和恢复入口。载体、保存期限、访问、删除和跨境处理由目标组织制度及平台权限定义；本契约不复制完整简历或隐藏思维链。
